# Design Specs: 띵동 홈페이지

## 1. Design Tokens
`src/app/globals.css`에 CSS 변수로 정의합니다.
- **Colors**: `--coral`, `--blue`, `--ink`, `--paper`, `--white`, `--yellow` 등
- **Typography**: Pretendard 폰트 (CDN 적용)
- **Spacing/Radius**: 4px 기반 간격, `--radius-sm/md/lg/xl`
- **Shadows**: `--shadow-sm/md/lg/coral/blue`

## 2. Component Hierarchy
1. `Header`: Sticky 네비게이션
2. `MenuOverlay`: 모바일 햄버거 메뉴
3. `Hero`: 메인 배너 및 통계
4. `PartnerMarquee`: 제휴 기관 띠 (애니메이션)
5. `About`: 회사 소개 카드 그리드
6. `Programs`: 프로그램 4종 카드
7. `WhyUs`: 다크 섹션 (6가지 이유)
8. `Instructors`: 강사진 카드
9. `Facility`: 갤러리 그리드
10. `Process`: 4단계 절차
11. `Reviews`: 후기 카드
12. `BigCTA`: 하단 체험 신청 배너
13. `Contact`: 문의 폼 및 지도
14. `Footer`: 사이트 하단 정보
15. `QuickMenu`: 하단 플로팅 버튼 (TOP 포함)

## 3. 기술 전략
- **스타일링**: CSS Modules 또는 Vanilla CSS(`globals.css` + `page.module.css`) 사용. (README의 선호도 존중)
- **상태 관리**: `Header`, `MenuOverlay`, `Contact`, `QuickMenu`는 인터랙션이 필요하므로 Client Component(`"use client"`)로 구현. 나머지는 Server Component.
- **애니메이션**: `globals.css`에 `@keyframes` 정의 후 클래스로 재사용.
